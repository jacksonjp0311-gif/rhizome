## What this is

A local-first, evidence-gated society of scripted agents that can now ask large mathematical questions and receive certified answers.

- Agents propose machine-checkable claims.
- The Oracle (now augmented by Sagebrush engines) verifies them.
- Results carry status: proven, conditional (e.g. GRH), or heuristic.
- Human authorization remains required for anything durable.
- Public, append-only record of everything.
